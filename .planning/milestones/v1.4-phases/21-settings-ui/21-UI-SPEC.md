# Phase 21 — UI Design Contract

> Visual and interaction contract for the Settings UI phase (AI Provider selector + Command-based model pickers).
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Extends the Phase 17 Settings contract carried in `src/components/settings/model-settings-form.tsx` — this phase extends the established slate design language, it does not introduce a new one.

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (`components.json` present) |
| Preset | radix-nova style, neutral baseColor, lucide icon library — default preset, no custom preset code (`registries: {}`) |
| Component library | Radix (unified `radix-ui` package, e.g. `import { Slot } from "radix-ui"`) **+ NEW `cmdk`** (vendored Command) |
| Icon library | lucide-react |
| Font | Geist Sans via `next/font/google` (`--font-sans`, `src/app/layout.tsx:8`) |

**New npm dependency this phase:** `cmdk` (installed by `npx shadcn@latest add command`). No other third-party runtime — `popover` and `input-group` are official shadcn components built on the already-present `radix-ui` package. React 19.2.4 is compatible with cmdk v1.

| Role | Size | Weight | Line Height | Class |
|------|------|--------|-------------|-------|

Weights declared: **400 (regular)** for all text, **600 (semibold)** for headings and the primary button. Family subtitles, `~latest`/`:free` suffix labels, and cost captions all use the 12px/400 caption style.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (white) | Page background, card surface (`bg-white`) |
| Secondary (30%) | `slate-50 #f8fafc` / `slate-100 #f1f5f9` / `slate-200 #e2e8f0` / `slate-500 #64748b` | Wells (`bg-slate-50`), dividers (`border-slate-100`), card borders (`border-slate-200`), all muted text (4.73:1 AA on white) |
| Accent (10%) | `slate-900 #0f172a` (oklch(0.205 0 0) `--primary` token) | Page H1, card titles, the **Save changes** primary button (`bg-primary`) |
| Destructive | `red-600 #dc2626` | Stale-model hints, error copy, `ERROR_COPY` messages (existing) — destructive semantics only |
| Warning (NEW) | `amber-700 #b45309` | **High-cost row cost captions only** (D-21-13) — 5.03:1 AA on white; amber-600 would fail AA at 12px, do not use |

Accent reserved for: page H1 + card titles (`text-slate-900`) and the Save changes primary button. **Not** used for: provider badges (neutral slate per D-21-09), the provider selector, hints, or picker rows.

**Provider badge (D-21-09/D-21-10):** `Badge variant="secondary"` — `bg-secondary text-secondary-foreground` (neutral light-gray pill, near-black text, ~15:1 contrast), pill radius (`rounded-4xl`), `text-xs`, h-5. Provider name text: `Anthropic` / `OpenRouter`. No color-coding, ever.

**New-row styling rules:**
- Cost caption: `text-[12px] font-normal leading-[1.4] text-slate-500`, prefixed `· ` (existing D-03 pattern).
- High-cost caption: same anatomy, **`text-amber-700`** instead of slate-500. Threshold: **`costInput >= 50`** (D-21-13 discretion default; verified against the committed snapshot: exactly 1 openrouter row trips it — `openai/o1-pro` at $150/M input — so the warning never floods the 336-row list).
- Family subtitle: `text-[12px] font-normal leading-[1.4] text-slate-500`, rendered as a second line under the model name for any row with a non-empty `family` (D-21-11).
- `~latest` / `:free` suffix labels: same caption style (12px/400/slate-500), inline after the model name (D-21-12).
- Provider-switch hint (D-21-01): `text-[14px] font-normal leading-[1.5] text-slate-600` — informational, matches the "Saved." confirmation tone, never red.

## Row Anatomy (model picker rows)

Prescriptive row structure inside `CommandItem` (all pickers, consistent):

```
Line 1: [Badge provider]?  {model name} {suffix label}? · {cost caption}
Line 2: {family}?   (muted 12px caption, only when family is non-empty)
```

- **Provider badge on rows: union fallback pickers ONLY** (D-21-10 required — type-to-filter mixes providers, so search results need identity; same-name disambiguation). The **primary picker is provider-scoped (SET-02)** — every row is the selected provider, so row badges are pure noise on 336 rows (PITFALLS 10) and are omitted; the provider is stated by the selector above, the section header, and the trigger badge. (Decided per the D-21-10 discretion note that dropdown row badges "may be redundant" where section headers carry identity.)
- **Trigger badges (closed state): required everywhere** — the primary trigger shows `{provider badge} {selected model name}`; the saved value is disambiguated at a glance (`claude-sonnet-5` vs `anthropic/claude-sonnet-5`).
- **Suffix labels** (D-21-12): appended immediately after the name when `id.startsWith('~')` → "always the latest"; when `id.endsWith(':free')` → "free tier — 50 req/day shared". Derived client-side from the id — the id is the source of truth (REG-03 includes these rows).
- **Cost caption**: existing "· $X / $Y per MTok" format; **amber-700 when `costInput >= 50`** (D-21-13), else slate-500.
- **Family subtitle**: line 2, rendered for any row with non-empty `family` (D-21-11 — OpenRouter rows; no nested provider→family subgroup headers, deferred).
- **Stale saved values**: render as a disabled `CommandItem` (badge shown when the provider is known, name from the server-resolved `savedChain` prop, raw-id fallback) + the red hint below the row — preserves the existing D-10/D-11 "replace or remove to re-enable Save" behavior.
- **Dedupe (existing D-08/D-09, widened to the union)**: a model chosen for one slot disappears from the other slots' options; the primary is never a fallback option. Applied over the 353-id union list.

## Interaction Contract

### Provider selector (SET-01, D-21-03)
- The always-valued selector sits **directly above the Primary model label** inside the AI Model Configuration card.
- **Control: the existing shadcn `Select`** (2 items: Anthropic, OpenRouter; no search needed). D-21-06 scopes the Combobox replacement to *model slots* ("the primary AND all fallback slots"); the provider selector is a 2-choice control, and `select.tsx` is retained for other consumers anyway. One consistent *model-picker* pattern; the provider selector is not a model picker.
- Initial state: provider of the saved primary (from `savedChain`), else `'anthropic'` (REG-05 default chain is the Anthropic fast path).

### Provider switch (SET-03, D-21-01/D-21-02/D-21-04)
1. Set provider state to the new provider.
2. **Keep-if-valid**: if the current draft primary is in the new provider's servable list, keep it — no hint. (Verified: the anthropic and openrouter id spaces are disjoint — zero overlap in the committed snapshot — so keep-if-valid always fails in practice and the hint always shows; the code still implements the check per D-21-01.)
3. **Reset**: else set primary to `defaults[newProvider].id` and show the non-blocking hint "Primary model reset to {defaultName} for {providerName}." under the selector.
4. **Fallbacks preserved verbatim** in the draft (D-21-02) — never cleared, never reordered, never silently dropped. The union pickers still render them; the chain may become cross-provider by design.
5. Save gating recomputes immediately against the union servable set (D-21-14) — a stale primary keeps Save blocked with the existing red hint (D-21-04). Server-side `invalid_model` remains the backstop.

### Model pickers (SET-02/SET-04/SET-06, D-21-05..D-21-08, D-21-11)
- **Primary picker**: options = `servableByProvider[provider]` (Anthropic: 1 row; OpenRouter: 336 rows). Provider section header inside the dropdown (provider name text, vendored group-heading style).
- **Fallback pickers** (cap 2, existing): options = union servable list (353 rows: 336 openrouter + 17 anthropic), **grouped by provider sections** (`CommandGroup` heading = `Anthropic` / `OpenRouter`, plain provider name — decided over the badge+name combo per the discretion note; row badges carry identity inside search results).
- **Type-to-filter search (D-21-07, cmdk)**: every `CommandItem`'s value = `[id, name, family].filter(Boolean).join(' ').toLowerCase()` — 'sonnet', 'anthropic/claude...', and 'anthropic' all surface the right rows. Search index includes family (D-21-07/D-21-11).
- **336-row usability (SET-06/PITFALLS 10)**: the vendored `CommandList` scrolls (`max-h-72`); groups + search are both P1 (locked); no virtualization needed at this scale — cmdk's filter + grouping is sufficient; every row is keyboard-reachable (arrow/enter/escape native cmdk).
- Open behavior: dropdown opens unfiltered (showing both provider groups in fallback pickers), search input focused.

### Save flow (unchanged contract)
- `staleIds = [primary, ...fallbacks].filter(id => id && !unionIds.includes(id))` — **widened from anthropic-only to the union servable set** (D-21-14); empty fallback rows (`''`) are in-progress edits, not stale (existing).
- Submit `{ primaryModel, fallbacks }` to `saveSettingsAction` (unchanged — already union-validating, REG-07). Draft preserved verbatim on failure (D-13). On success: `Saved.` + the saved-chain recap renders while the draft equals `lastSaved`; it hides once the user edits any slot.

## Props & Data Contract (server → client, props-only)

`settings/page.tsx` widens its computed props; `catalog.json` never enters a client bundle (T-17-09). Trimmed shapes only — raw catalog stays server-side. All row lookups MUST be provider-scoped (`m.id === id && m.providerID === <provider>` — Anti-Pattern 1; the snapshot dual-lists ids).

| Prop | Type | Notes |
|------|------|-------|
| `saved` | existing `{primaryModel, fallbackModels} \| null` | unchanged |
| `providers` | `{ id: 'anthropic'\|'openrouter'; name: 'Anthropic'\|'OpenRouter' }[]` | from `SERVABLE_PROVIDERS` (catalog.ts) |
| `servableByProvider` | `Record<ModelProviderId, ServableModel[]>` | per-provider servable lists (anthropic 1, openrouter 336) via `getServableIdsForProvider` |
| `unionServableModels` | `ServableModel[]` | `getUnionServableIds` → 353 rows, for fallback pickers |
| `defaults` | `Record<ModelProviderId, { id, name }>` | from `PROVIDER_DEFAULT_MODELS` + `getModelDisplayName` (reset-to-provider-default source, D-07) |
| `savedChain` | `{ id, name, providerID: ModelProviderId \| null }[]` | saved primary + fallbacks with server-resolved provider identity (`getProviderForModelId`) for trigger badges + stale-row rendering; `providerID: null` when catalog-absent |

`ServableModel` (extended from today's `{id, name, costInput, costOutput}`): `{ id, name, family, providerID, costInput, costOutput }` — `family` and `providerID` are new; derived client-side, never from the raw catalog. `~`/`:free` label flags are derived client-side from `id`.

## Accessibility & Contrast

- All muted text AA-safe on white: slate-500 4.73:1, red-600 4.5:1, amber-700 5.03:1, badge secondary ~15:1. No color-only meaning anywhere (D-21-09: provider identity is text, not color).
- Every picker trigger is a real `<button>` (Popover trigger) with an accessible name: "Primary model", "Fallback model 1", "Fallback model 2" (existing `id` pattern: `primary-model`, `fallback-1`, `fallback-2`). Provider selector labeled "AI provider".
- Search is a labeled input inside the Combobox; results list is a listbox with native cmdk arrow-key/enter/escape keyboard support.
- Move/remove fallback buttons keep their existing `aria-label`s (`Move fallback up/down`, `Remove fallback`).
- 44px touch targets: existing ghost icon-buttons and button heights are preserved — no new icon-only targets introduced.
