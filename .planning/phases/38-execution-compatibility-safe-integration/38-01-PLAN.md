<objective>
Define the compatibility adapter's contracts and immutable snapshot boundary before any route or UI wiring. Use the existing JSONB columns with this exact representation: `analysis_run.template_snapshot.custom` stores the selected custom identity/version and validated authored configuration; `analysis_run.execution_snapshot.customOutputSchema` stores the normalized bounded output schema plus its server-owned adapter version; and only custom model output uses a top-level `custom` object whose validated values are later persisted at `analysis_run_result.raw_audit.customOutput`. Fixed runs retain the legacy `{ narrative, findings }` envelope and omit `custom` entirely. No SQL migration, new column, new foreign key, or parallel run table is planned.

Purpose: D-38-12 and VER-03 require replay to depend on immutable, server-resolved values rather than mutable custom-agent state. D-38-13 leaves exact fields and output nesting to planning discretion; this plan makes that choice explicit while preserving D-38-08 through D-38-11 and the v1.7 fixed branch.
Output: Strict fixed/custom selection contracts, immutable snapshot extension, and deterministic contract/snapshot tests.
</objective>
