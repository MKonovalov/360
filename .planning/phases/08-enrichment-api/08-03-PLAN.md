<task>
  <name>Task 1: apollo.ts client</name>
  <steps>
  - `export type EnrichmentResult = { ok: true; fields: EnrichedField[] } | { ok: false; reason: string };`
  - Base `const APOLLO_BASE = 'https://api.apollo.io/api/v1';`
  - `enrichOrganization(domain: string): Promise<EnrichmentResult>`:
    - If `!env.APOLLO_API_KEY` → `{ ok:false, reason:'not_configured' }` (no network).
    - Normalize domain via `normalizeDomain` (dedupKeys). `GET ${APOLLO_BASE}/organizations/enrich?domain=<encoded>`, headers `{ 'X-Api-Key': env.APOLLO_API_KEY, 'Content-Type':'application/json', 'Cache-Control':'no-cache' }`, `cache:'no-store'`, `signal: AbortSignal.timeout(10000)`.
    - Non-2xx → log metadata + `{ ok:false, reason:'http_'+status }`.
    - Parse JSON via permissive Zod `.passthrough()`; read `.organization`. Absent/null → `{ ok:false, reason:'no_match' }`. Present → `apolloMapCompany(org)`; if it yields 0 fields → `{ ok:false, reason:'no_match' }`, else `{ ok:true, fields }`.
    - Wrap in try/catch → `{ ok:false, reason:'network' }`. NEVER log the caught error object or body (could contain PII/secrets).
  - `enrichPerson(email: string): Promise<EnrichmentResult>`: same shape but `POST ${APOLLO_BASE}/people/match?email=<encoded>` (no reveal_* params), read `.person`, map via `apolloMapPersona`.
  - Metadata log helper: `console.info(JSON.stringify({ event:'enrichment_call', kind, ok, status }))` — kind = 'organization'|'person'. No recordId here (client is record-agnostic; the Server Action logs recordId).
  </steps>
