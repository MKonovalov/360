<task>
  <name>Task 1: runEnrichment action</name>
  <steps>
  - `'use server'` header. Import `requireStaffAccess`, the client, `buildEnrichmentPlan`, `getCompanyById`/`getPersonaById`.
  - `export async function runEnrichment(entityType: 'company'|'persona', recordId: number): Promise<{ ok: true; plan: EnrichmentPlanRow[] } | { ok: false; reason: string }>`.
  - `await requireStaffAccess()` FIRST.
  - Load the record. Company: if `!company.domain` → `{ ok:false, reason:'no_match_key' }`. Persona: if `!persona.email` → same.
  - Call `enrichOrganization(domain)` / `enrichPerson(email)`. On `!result.ok` → log metadata + return `{ ok:false, reason: result.reason }`.
  - On ok → `buildEnrichmentPlan(currentRecord, result.fields)`. If plan is empty (everything identical) → `{ ok:true, plan: [] }` (UI shows "already up to date"). Else `{ ok:true, plan }`.
  - `console.info(JSON.stringify({ event:'enrichment_run', entityType, recordId, ok: result.ok, reason: result.ok ? undefined : result.reason }))` — no body.
  </steps>
  <verify>`npx tsc --noEmit` clean; `grep -n "requireStaffAccess\|no_match_key" src/app/actions/enrichment.ts`</verify>
</task>

<task>
  <name>Task 2: commitEnrichment action</name>
  <steps>
  - `export async function commitEnrichment(entityType:'company'|'persona', recordId:number, accepted: Record<string,string|string[]>): Promise<{ ok:true } | { ok:false; reason:string }>`.
  - `await requireStaffAccess()` FIRST.
  - Validate `accepted` keys against an allowlist of writable columns per entity (company: industry, employeeCountBand, hqLocation, revenueBand, ownershipType, techStack; persona: title, seniority, linkedinUrl). Drop any key not in the allowlist (defense-in-depth — never write name/domain/email).
  - If accepted is empty after filtering → `{ ok:true }` (no-op, nothing to write).
  - Call `applyCompanyEnrichment` / `applyPersonaEnrichment`. Log metadata. `revalidatePath` for the detail route so the UI reflects the write (match import.ts's revalidate convention). Return `{ ok:true }`.
  </steps>
  <verify>`npx tsc --noEmit` clean; `grep -n "commitEnrichment\|applyCompanyEnrichment\|applyPersonaEnrichment" src/app/actions/enrichment.ts`</verify>
</task>
