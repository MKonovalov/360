## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client subject/template IDs → server resolver | Inputs may pair a valid ID with the wrong entity kind or stale catalog row. |
| mutable signal/template catalog → immutable run intent | Catalog rows can change after creation and must be copied allowlist-only. |
| model/policy settings → persisted JSONB | Server settings may contain credentials or private policy data. |
