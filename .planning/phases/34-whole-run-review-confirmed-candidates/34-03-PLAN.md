| Boundary | Description |
|---|---|
| Browser → Server Action | Browser can replay or forge run IDs/decisions and is never trusted for actor identity. |
| Server page → packet projection | Review UI must receive retention-safe, non-sensitive packet/provenance fields only. |
| New run review section → legacy proposal queue | Shared navigation must not cross into legacy proposal/live Signal mutation semantics. |

</threat_model>
