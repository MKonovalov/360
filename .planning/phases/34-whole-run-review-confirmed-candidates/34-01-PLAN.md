## Trust Boundaries

| Boundary | Description |
|---|---|
| Client/action input → review contract | Run IDs and decisions are untrusted Server Action input. |
| Phase 33 packet → review identity | Packet/result identity and hash must be authoritative and immutable. |
| Review identity → candidate projection | A terminal decision must not be confused with packet existence or legacy proposal state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-34-01 | Tampering | review decision schema/contracts | mitigate | Closed decision enum, positive IDs, unique run/result identities, packet hash capture, and no mutation fields. |
| T-34-02 | Spoofing/Elevation | actor contract | mitigate | Actor is a server-result field; later action must derive it from `requireStaffAccess()`, never client input. |
| T-34-03 | Information disclosure | candidate provenance contract | mitigate | Require explicit target/signal discriminators and source IDs; exclude private reasoning/provider fields and retain Persona boundary. |
| T-34-SC | Tampering | dependency/package surface | mitigate | No package installs or providers; later scope audit blocks forbidden imports/writes. |
</threat_model>
