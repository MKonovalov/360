<objective>
Write `src/components/settings/model-picker.tsx` — the single reusable Combobox wrapper (D-21-05/06) that replaces shadcn Select on the primary AND all fallback model slots. It is the classic shadcn searchable-select pattern: Popover trigger (Button showing the selected value + provider badge + chevron) + Command list with type-to-filter search, provider CommandGroup sections, per-row check state, badges, suffix labels, cost warnings, and a stale-row rendering path.

Purpose: One consistent picker everywhere (D-21-06). The wrapper's two silent-failure traps are locked here: (1) the vendored v4 `CommandItem` auto-renders its Check icon gated on `data-[checked=true]` but cmdk 1.1.1 never sets that attribute — the wrapper MUST pass `data-checked={value === m.id}` per row (RESEARCH Pitfall 1, the #1 failure point); (2) `onSelect` delivers the COMPOSITE search string, not the id — the wrapper must reverse-lookup to the id before `onChange` or the draft stores the composite and Save fails `invalid_model` (Pitfall 3).
Output: The wrapper component consumed by the form in plan 21-05 for all three model slots.
</objective>
