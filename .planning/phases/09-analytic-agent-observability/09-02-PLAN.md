<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent output → DB | Model-generated proposal data crosses into durable storage — gated + schema-validated first |
| proposal → signal (Accept) | Staff-triggered write to the live signal table — must be exactly-once (T-09-07) |
| app → Langfuse | Correction annotations + traces leave the app (D-14 mirror) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Spoofing | analyze flow entry | mitigate | Callers gated by `requireStaffAccess()` in the Route Handler / actions (Plan 03) — analyzeCompany itself holds no auth (single gating layer) |
| T-09-02 | Tampering | web content → agent | mitigate | Content stays tool-result-only; structured schema + gate constrain output (Task 1 chains gate before any persist) |
| T-09-03 | Tampering | orphan/fabricated citations | mitigate | Gate fails closed → `{ ok:false, reason:'gate_failed' }`, nothing persists (Task 1); appendix from real tool results (D-02) |
| T-09-04 | Information Disclosure | API keys | mitigate | Keys never enter this layer — server-only env (09-01 Task 2); no logging of keys |
| T-09-05 | DoS / cost | runaway paid calls | mitigate | Single company per run; `isStepCount(12)` cap; gate short-circuits before DB writes |
| T-09-06 | Tampering | mass-proposal flooding | mitigate | Proposals only flow from gated runs (Task 1) + post-dedup filter; accept/reject staff-only (Plan 03) |
| T-09-07 | Tampering | race: duplicate signal writes | mitigate | acceptProposal status-guarded conditional UPDATE (0 rows ⇒ idempotent no-op) + unique index `signal(company_id, signal_type)` backstop (09-01); NO `db.transaction()` — neon-http driver throws |
| T-09-08 | Information Disclosure | trace data leakage | mitigate | evidenceAppendix retention tags; internal company names only; corrections store traceId but no personal data beyond optional staff note |
| T-09-SC | Tampering | npm installs | mitigate | Already audited 10/10 [OK] (09-01 Task 2); no new packages in this plan |
</threat_model>
