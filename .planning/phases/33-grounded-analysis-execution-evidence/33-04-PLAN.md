| Boundary | Description |
|---|---|
| immutable run snapshot → model/tool request | Snapshot fields become external service inputs. |
| Firecrawl/web content → model prompt | Retrieved content can contain prompt injection or malicious URLs. |
| model/tool result → adapter output | Generated output is untrusted and must remain unpersisted until validation. |
