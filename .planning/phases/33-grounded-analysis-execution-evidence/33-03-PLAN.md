<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Firecrawl result → evidence normalizer | External web content and URLs are attacker-controlled data. |
| model citation → source link | Model output may hallucinate or manipulate citation identity. |
| normalized packet → persistence | Only validated, server-owned structures may cross into product storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-33-07 | Information Disclosure | URL/source acquisition | mitigate | HTTPS-only canonical validator rejects private/local/credentialed targets and unsupported schemes. |
| T-33-08 | Tampering | citation/finding resolver | mitigate | Server-derived source set, exact canonical equality, content hash/excerpt anchoring, snapshot signal IDs. |
| T-33-09 | Tampering/Elevation | retrieved page content | mitigate | Delimit as untrusted data, reject tool-policy/prompt-injection violations, never execute page instructions. |
| T-33-10 | Information Disclosure | Persona source content | mitigate | Classification and approved retention/redaction checks reject disallowed personal data. |
| T-33-SC | DoS/cost | source bounds | mitigate | Enforce policy source/result/excerpt/content limits before packet acceptance. |
</threat_model>
