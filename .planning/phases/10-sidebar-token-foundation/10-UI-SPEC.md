## Phase Decisions (LOCKED — the 4 Phase-0 gates)

### D1. Logo treatment — text wordmark + collapsed letter-mark

No ArcLumen logo asset exists (public/ holds only Next/Vercel defaults). Locked: **text wordmark, zero new assets.**

- **Expanded (Phase 12):** "ArcLumen 360" — Geist 15px/600, `text-sidebar-foreground` — with an org sub-label "ArcLumen Partners" at 12px/400, `text-sidebar-foreground/70` (4.89:1 — passes). Both styled with sidebar tokens only.
- **Collapsed rail (Phase 13):** a 28px `rounded-md` letter-mark box — `bg-sidebar-primary text-sidebar-primary-foreground` (dark `#333333` box, white "A" glyph, Geist 600 13px). Fits the 48px rail with 10px margins.
- Implementable with tokens only; no SVG, no favicon change, no hotlinked assets.

### D2. Feedback destination — team-inbox mailto

Locked: **`mailto:hello@arclumenpartners.com?subject=360%20sidebar%20feedback`** (default inbox — confirm/replace the address at plan time if a different team inbox is preferred). Rationale: research's primary mapping (FEATURES.md "Map to a real destination (mailto: team inbox)"), zero infra, no invented wiki page, and an Arcpedia link would require creating a page that does not exist. Implemented as the "Give us feedback" pill in Phase 12; the **copy and destination are locked here**.

### D3. Collapse target width — 48px (stock 3rem)

Locked: **48px — shadcn's shipped `--sidebar-width-icon: 3rem`** (sidebar.tsx:31,135). **No override.** Rationale: fits 32px icon buttons (`size-8!`), 16px lucide icons, the 28px letter-mark, and right-side tooltips exactly; keeps the collapse/resize/`⌘B` contract byte-identical (COLR-02 preservation); zero drift from the vendored primitive. Labels fade while icons stay, width animated (primitive's `transition-[width] duration-200`).

### D4. Portal policy — portaled, light app-theme, NO carve-out

Locked: **Radix default portals (`DropdownMenuContent`/`TooltipContent` render at `document.body`), light app-theme — zero edits to `dropdown-menu.tsx`/`tooltip.tsx`.** Rationale: over the light `#fbfcfd` panel, the white `bg-popover` dropdown is visually coherent (light-on-light, no flash) — the dark-panel carve-out from PITFALLS Pitfall 2 is **moot**. The Phase 12 user-menu dropdown and Phase 13 collapsed-rail tooltips (`bg-foreground text-background`, dark-on-white — legible over light content) both render app-theme by default.

## Token Contract (the Phase 10 deliverable)

One scoped block in `src/app/globals.css`, appended after the existing `:root` block. All 8 tokens set as a **complete verified AA set** (QLTY-02); values measured 2026-08-01 with WCAG relative-luminance math.

```css
/* Phase 10 — sidebar light theme (scoped; zero vendored edits; @theme inline untouched) */
[data-sidebar="sidebar"] {
  --sidebar: #fbfcfd;                   /* 1 panel — reference value (FEATURES.md) */
  --sidebar-foreground: #333333;        /* 2 base text 12.30:1; /70 labels 4.89:1 */
  --sidebar-primary: #333333;           /* 3 primary surface (letter-mark box, buttons) */
  --sidebar-primary-foreground: #ffffff;/* 4 on primary 12.63:1 */
  --sidebar-accent: #909090;            /* 5 hover/active pill — 3.11:1 vs panel (AA 1.4.11) */
  --sidebar-accent-foreground: #111111; /* 6 on pill 5.91:1; on panel 18.38:1 */
  --sidebar-border: #e5e7eb;            /* 7 hairline — gray-200 reference (decorative) */
  --sidebar-ring: #787878;              /* 8 focus ring — 4.30:1 vs panel */
}

/* Companion rules — same block/location in globals.css. Required for PANE-01/QLTY-02
   WITHOUT vendored edits (PITFALLS Pitfalls 3 & 5): */
[data-slot="sidebar-container"] {
  border-color: var(--sidebar-border);  /* hairline uses --sidebar-border, not global --border */
  border-right-width: 0.5px;            /* desktop-only element — reference 0.5px hairline */
}
[data-sidebar="sidebar"] * {
  outline-color: var(--sidebar-ring);   /* neutralizes global outline-ring/50 leak (≈1.7:1) */
}
```

**Mechanism notes (verified against vendored `sidebar.tsx`):**
- `[data-sidebar="sidebar"]` matches the desktop `sidebar-inner` (sidebar.tsx:242, `bg-sidebar`) **and** the mobile `SheetContent` (sidebar.tsx:186, `bg-sidebar`) — one block themes expanded, icon-collapsed, and the mobile sheet (PANE-03).
- Custom-property inheritance means all descendants (menu buttons, group labels, header/footer zones) resolve the scoped values — enabled by the load-bearing `@theme inline` mapping (globals.css:13-20).
- `[data-slot="sidebar-container"]` exists **only on desktop** (the mobile branch renders SheetContent) — the 0.5px hairline cannot leak to the sheet.
- Do **not** touch: `:root` sidebar tokens (globals.css:76-83), the `.dark` block, `@theme inline`, `--ring`/`--border` globally, or `src/components/ui/sidebar.tsx`.

**Divergences from the Exa reference — deliberate, mandated (audit-critical):**

| Reference value | Measured vs panel | Why diverged | Token |
|---|---|---|---|
| `rgba(0,0,0,0.04)` active/hover fill | **1.09:1** — FAILS WCAG 1.4.11 | PITFALLS Pitfall 3: "active pill ≥3:1 — do not copy that tradeoff for a daily-use internal tool" | `--sidebar-accent: #909090` (3.11:1) |
| `#444444` nav text | 9.4:1 raw, but `/70` labels → **4.0:1 FAIL** | Group labels render at `text-sidebar-foreground/70` | `--sidebar-foreground: #333333` (12.30:1 / 4.89:1) |
| `#888888` section labels | 3.4:1 raw — FAILS 4.5:1 | Same /70 mechanism | `--sidebar-foreground/70` (4.89:1) |
| `oklch(0.708 0 0)` ring (`#a3a3a3`) | 2.44:1 — FAILS 3:1 | Global `--ring` also leaks via `outline-ring/50` (1.7:1) | `--sidebar-ring: #787878` (4.30:1) + scoped outline rule |

Kept verbatim from the reference: panel `#fbfcfd`, hairline `#e5e7eb` gray-200, 4px radius pill, 0.5px hairline width.

## Interaction & State Contract

| State | Behavior | Contract |
|-------|----------|----------|
| Idle | Nav row, 30px, `text-sidebar-foreground` (#333333) | 12.30:1 on panel |
| Hover | Full-row `hover:bg-sidebar-accent` (#909090) pill, text → `hover:text-sidebar-accent-foreground` (#111111) | 3.11:1 pill boundary (AA 1.4.11) |
| Active | Full-row `data-active:bg-sidebar-accent` (#909090) + `data-active:font-medium` + `data-active:text-sidebar-accent-foreground` (#111111), 4px radius | Active vs hover distinguished by **font-weight + darker text** (both share the pill fill — reference behavior; hover==active fill is authentic to Exa) |
| Focus-visible | `ring-sidebar-ring` (2px ring) + scoped `outline-color` override | Ring 4.30:1 on panel — visible in expanded and collapsed rail |
| Collapsed (48px) | Icons stay, labels fade (`group-data-[collapsible=icon]`), tooltips appear right-side | Tooltips `bg-foreground text-background` (dark-on-white, legible over light content) — app-theme, portaled |
| Mobile sheet | `bg-sidebar` SheetContent inherits the scoped block automatically | Same panel, same tokens (PANE-03) |
| Active on `/companies/[id]` | Highlight must persist — **never** simplify to exact equality | Locked by `getActiveNavKey` tests below (QLTY-01) |

**QLTY-01 — `getActiveNavKey` contract (shipped this phase):**
- File: `src/lib/nav.ts` — named export (repo convention: `src/lib/sanity.ts` precedent), pure function:
  `getActiveNavKey(pathname: string): 'start' | 'companies' | 'personas' | 'reviews' | null`
- Rules: `'/'` → `'start'` (exact — every route is a string-prefix match for `/`); `'/companies'`, `'/personas'`, `'/reviews'` → prefix match **with boundary guard** (pathname is `'/companies'` or starts with `'/companies/'`) so sibling prefixes like `/companies-archive` cannot false-positive; everything else (`'/sign-in'`, unknown) → `null`.
- Tests: `src/lib/nav.test.ts` (Vitest, node env — matches existing `src/**/*.test.ts` include): `'/'`, `'/companies'`, `'/companies/123'`, `'/companies/123/edit'`, `'/personas'`, `'/personas/456'`, `'/reviews'`, `'/reviews/9'`, `'/sign-in'`, `'/companies-archive'`, `''`.
- Consumer: `app-sidebar.tsx` swaps its 4 inline `isActive` expressions to `getActiveNavKey(pathname)` in Phase 11; **this phase ships the function + tests only** (roadmap SC #5).
